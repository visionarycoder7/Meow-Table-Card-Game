# Code of Conduct

Meow Table is a place to play and build together with respect. This code applies to repository discussions, issues, pull requests, project-run playtests, and interactions where someone represents the project.

## Expected behavior

- Welcome players and contributors with different backgrounds and experience levels.
- Give specific, respectful feedback about the work. Accept corrections and acknowledge contributions.
- Respect boundaries and keep private room links, messages, and personal information confidential.

Harassment, threats, discriminatory language, unwanted sexual attention, impersonation used to harm others, and sharing someone’s private information without permission are unacceptable.

## Reporting and response

Use an established private channel to contact a maintainer. If you need one, open a [GitHub issue](https://github.com/visionarycoder7/Meow-Table-Card-Game/issues/new) titled **Request for private conduct contact**. Include only the request in public. Share relevant links or screenshots privately after a maintainer replies. For conduct on GitHub itself, you can also use [GitHub’s abuse reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Maintainers should limit sharing of reports to what is needed to review and address them. Depending on the behavior and its impact, they may remove content, issue a warning, or restrict participation. You may request reconsideration through the same private channel. Retaliation for making or supporting a good-faith report is unacceptable.
