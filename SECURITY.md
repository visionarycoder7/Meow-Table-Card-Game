# Security policy

Report issues affecting the [hosted game](https://meow-table.meow2004.workers.dev/) or current `main` here. Examples include unauthorized room or seat access, exposure of another player’s hand, and accidental disclosure of session tokens. Use [GitHub Issues](https://github.com/visionarycoder7/Meow-Table-Card-Game/issues) for ordinary gameplay bugs.

## Report privately

1. Check the repository’s [Security advisories](https://github.com/visionarycoder7/Meow-Table-Card-Game/security/advisories) page. If **Report a vulnerability** is available, submit the report there. [GitHub private reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)
2. If the button is unavailable, ask the maintainer for a private reporting channel. You can open a [GitHub issue](https://github.com/visionarycoder7/Meow-Table-Card-Game/issues/new) titled **Request for private security contact**. Keep the public issue to the contact request.
3. Once you have a private channel, share the affected URL or revision, expected and observed behavior, scope, and a short reproduction using your own accounts and rooms. Redact seat tokens, real invite codes, IP addresses, and personal data from logs or screenshots.

Test on localhost or in rooms you control. Stop if you encounter another player’s data or risk disrupting the hosted service. Coordinate disclosure privately while the maintainers assess the issue and prepare any fix.
